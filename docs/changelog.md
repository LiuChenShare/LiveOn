# 版本更新记录

<!-- 格式：每次版本迭代由产品经理在收尾阶段追加 -->

## v1.0.1 - 2026-04-21
**需求摘要**：背包管理增强 — 物品使用（种植）、丢弃、类型分类与排序 

**新增功能**：
- 种子类物品显示「使用」按钮，点击后可选择空闲地块种植
- 所有物品显示「丢弃」按钮，支持输入数量并二次确认
- 物品类型分类体系（种子/材料/装备/消耗品/其他）
- 背包列表按物品类型排序，同类型按数量降序
**Bug修复**：
- 修复 RemoveItems 方法逻辑错误（== 改 !=）

## v1.0 - 2026-04-13
**需求摘要**：项目初始版本，建立游戏基础框架
**新增功能**：
- 实体继承体系（Entity → TreeEntity / SeedEntity）
- 区块系统（12 块土地，支持种植/砍树/修剪）
- 种子生长机制（10 分钟成熟为杂树）
- 树木生长机制（每小时增长 30%）
- 背包系统（树枝、木材、杂树种子）
- Log4Net 按等级分文件日志
- 前端暗色森林主题 UI
**变更文件**：项目初始化
