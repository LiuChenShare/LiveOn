# v1.0.1 背包管理增强

## 需求背景

当前背包物品只按编码分组显示名称和数量，无法使用物品，也无法丢弃不需要的物品。玩家积攒了大量材料后缺少管理手段。

## 功能描述

### 1. 物品使用

- 背包中可种植的种子（有 ToEntityCode 的物品）显示「使用」按钮
- 点击「使用」后打开区块选择面板，选择一个空闲区块执行种植
- 使用后消耗一个该物品

### 2. 物品丢弃

- 每种物品显示「丢弃」按钮
- 点击后弹出确认框，输入丢弃数量（默认 1，最大为当前持有数量）
- 确认后从背包中移除对应数量的物品
- 丢弃的物品直接消失，不可恢复

### 3. 背包排序

- 背包列表按物品类型排序：种子类优先，然后材料类，最后其他

### 4. 物品增加类型
目前有材料类、装备类、消耗品类

## 验收标准

- [ ] 种子类物品显示「使用」按钮，点击后可选择空闲区块种植
- [ ] 所有物品显示「丢弃」按钮，支持输入数量并二次确认
- [ ] 丢弃后物品从背包消失，API 返回的物品列表中不再包含
- [ ] 背包列表按种子优先、数量降序排列
- [ ] 已删除的物品不影响排序和统计
